# Using Codex instead of Claude Code

Switch the coding agent and build with Codex

Click-by-click video tutorial, 1:54. GameStudio 0.1.0, Blender 5.2.2 or newer.

## 00:03 Step 1: Open the Edit menu

GameStudio works with Claude Code or with Codex, OpenAI's coding agent. To build with Codex, open the Edit menu,

## 00:10 Step 2: Choose Preferences...

and choose Preferences.

## 00:14 Step 3: Open Add-ons

Go to Add-ons.

## 00:16 Step 4: Expand GameStudio

Click the arrow next to GameStudio to show its settings.

## 00:20 Step 5: Set Coding agent to Codex

Under Coding agent, choose Codex. From now on, the launcher, the welcome and the agent button in the top bar open Codex.

## 00:28 Step 6: Close the Preferences

That's all it takes. Close the Preferences.

## 00:31 Step 7: Open the GameStudio menu

The agent button in the top bar now says Codex. To start Codex, open the GameStudio menu,

## 00:38 Step 8: Choose Open in Codex

and choose Open in Codex.

## 00:41 Step 9: Install Codex if it's missing

If Codex isn't installed yet, GameStudio offers to install it, with OpenAI's official installer. It needs no administrator rights, and Codex opens in your project when it's ready.

## 00:53 Step 10: Click Open

The first time, GameStudio connects Codex to your project: it adds Codex's copy of the skills and the link to Blender. Click Open.

## 01:02 Step 11: Codex starts: click Done

Codex starts in a terminal, in your project folder. The first time, it asks you to sign in, and to trust the folder. Click Done.

## 01:10 Step 12: Tell Codex what you want

Now, in the terminal, tell Codex what you want in plain words. Here: put five mossy rocks of different sizes around the lawn.

## 01:18 Step 13: Watch the rocks appear

Codex looks at the scene first, then builds. The rocks appear in Blender as it works, and the status bar shows what Codex is doing.

## 01:27 Step 14: Click Codex in the top bar

Codex is done. When you close it, the agent button in the top bar still says Codex. Click it.

## 01:33 Step 15: Next time, click Open in Codex

It lists everything Codex did, and each step can be undone. Next time, click Open in Codex right here, and Codex starts in your project again.

## 01:42 Done: Codex starts again

That's how to use Codex instead of Claude Code: choose it once in the preferences, and everything else works the same way.
