# From one line to a playable game

Claude Code builds a game in Blender from one brief

Click-by-click video tutorial, 2:00. GameStudio 0.1.0, Blender 5.2.2 or newer.

## 00:03 Step 1: Describe your game in one line

Here's a new Starter project, Sky Gems, with Claude Code open in its folder. Describe your game in one line: collect all the gems on a floating island before the timer runs out.

## 00:14 Step 2: Claude checks Blender and plans

Claude Code checks that Blender is connected, then writes a one-page plan: an island, six gems and a one-minute timer.

## 00:22 Step 3: Watch the island appear

Then it builds with GameStudio's kits: a floating island from the terrain kit replaces the lawn, with the player on it.

## 00:29 Step 4: Gems become collectibles

Six gems follow, each just above the ground, with the Collectible component, so the player can pick them up.

## 00:36 Step 5: Scroll out to see it float

While Claude works, scroll out in the 3D Viewport to see the whole island floating.

## 00:41 Step 6: Claude writes the timer code

The timer is new code: a small TypeScript system that counts down from sixty seconds, and shows Time's up at zero, or if you fall off.

## 01:06 Step 7: Open the scene list

Menus and the HUD are made in Blender too, so Claude opens the screens file. To watch, open the scene list in the top bar.

## 01:13 Step 8: Type HUD and press Enter

Type HUD and press Enter: the HUD is the screen that stays up while you play.

## 01:19 Step 9: A timer joins the HUD

Claude adds a timer to the HUD, across from the score, and saves.

## 01:23 Step 10: Claude playtests the game

Back in the level, Claude playtests in a hidden browser: it presses Play and runs into the first gem. The gem counts, the clock runs, and there are no errors.

## 01:33 Step 11: Press F5 to play

Claude says the game is ready. Press F5 to play it yourself.

## 01:37 Step 12: Click Play in the game

Click Play on the title screen. That also gives the game your mouse and keyboard.

## 01:42 Step 13: Hold W to grab a gem

The clock starts at one minute. Hold W to run to the gem ahead.

## 01:47 Done: One line, one playable game

One gem down, and the clock is ticking. From one line, Claude Code built a game you can play, and every part of it is yours to change in Blender.
