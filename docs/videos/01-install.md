# Install GameStudio

From the zip to a ready extension

Click-by-click video tutorial, 1:27. GameStudio 0.1.0, Blender 5.2.2 or newer.

## 00:03 Step 1: Open the Edit menu

To install GameStudio, start in Blender and open the Edit menu.

## 00:07 Step 2: Choose Preferences...

Choose Preferences.

## 00:10 Step 3: Open Get Extensions

In the Preferences window, go to Get Extensions.

## 00:14 Step 4: Open the menu at the top right

Blender asks about online access here. You don't need it to install from a file, so leave it, and open the small menu at the top right.

## 00:22 Step 5: Choose Install from Disk...

Choose Install from Disk.

## 00:24 Step 6: Go to Downloads

A file browser opens. Go to your Downloads folder,

## 00:28 Step 7: Select gamestudio-0.1.0.zip

select the GameStudio zip you downloaded,

## 00:32 Step 8: Click Install from Disk

and click Install from Disk.

## 00:34 Step 9: Click Open Demo

GameStudio is installed, and it welcomes you with the three steps from a project to a game. To try it, click Open Demo.

## 00:42 Step 10: Click Allow Online Access and Set Up

The demo opens, and GameStudio sets itself up the first time. It shows what it downloads: Node.js, the game packages and a game browser, about two hundred and thirty megabytes, once, into its own folder. Click Allow Online Access and Set Up.

## 00:58 Step 11: Node.js downloads

The setup runs in the background, with its progress in the status bar. First Node.js,

## 01:03 Step 12: The game packages download

then the game packages,

## 01:06 Step 13: The game browser downloads

then the game browser. You can keep working in Blender meanwhile.

## 01:10 Step 14: Open the GameStudio menu

When the status bar is clear, the setup is done. Open the new GameStudio menu in the top bar to check.

## 01:17 Done: GameStudio is ready

It says the setup is done. GameStudio is installed and ready, with the demo game open.
