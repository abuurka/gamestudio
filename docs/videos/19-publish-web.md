# Publish your game to the web

Build Web, the dist folder, and a test in a browser

Click-by-click video tutorial, 2:02. GameStudio 0.1.0, Blender 5.2.2 or newer.

## 00:03 Step 1: Open the Scene tab

Gem Island is ready to share. Publishing starts in the Properties: open the Scene tab.

## 00:09 Step 2: Press Ctrl+Space for room

Its Game Project panel has everything for a web build. Press Control Space over the Properties to give it the whole window.

## 00:16 Step 3: Scroll down to Build

Scroll down, past Blender's own scene settings, to the levels and the build.

## 00:21 Step 4: Click Export All

First, click Export All, so the build gets the latest version of every level and menu.

## 00:26 Step 5: Check the export's size

The project box shows the export's size, triangles and draw calls. Lower numbers load and run faster on the web.

## 00:34 Step 6: Click Build Web

Now click Build Web.

## 00:37 Step 7: Wait for the build

GameStudio builds it in the background: it bundles the code, compresses the levels and copies the sounds and menus.

## 00:45 Step 8: Scroll down to the result

It's done. Scroll down a little to see the result.

## 00:48 Step 9: Open Output Folder shows it

The finished game is in the dist folder, inside your project. Open Output Folder shows it in your file manager.

## 00:55 Step 10: Open the Editor Type menu

You can also look inside right here in Blender. Open the Editor Type menu,

## 01:01 Step 11: Choose File Browser

and choose File Browser.

## 01:04 Step 12: Go up one folder

It opens in your project's scenes folder. Click the arrow pointing up to go to the project folder.

## 01:10 Step 13: Add dist to the path

Double-click dist to open it, or, as here, click the path at the top, press End, type dist, and press Enter.

## 01:18 Step 14: Keep THIRD-PARTY-NOTICES.md with it

That's your whole game: index.html starts it, and the folders hold its code, levels and sounds. THIRD-PARTY-NOTICES.md lists the licences of the libraries inside. It must always stay with the game.

## 01:33 Step 15: Click Play in the browser

To test it before you upload it, serve the dist folder from your computer, as the manual shows, and open it in a browser. Click Play.

## 01:42 Step 16: It plays like in Blender

It plays just as it did in Blender. It's the same game, now a website.

## 01:47 Done: Upload dist to the web

To publish, upload everything in dist: zip it for itch.io as an HTML game, or put it on GitHub Pages, notices included. That's your game, on the web.
