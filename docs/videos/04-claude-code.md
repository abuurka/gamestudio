# Build with Claude Code

Describe what you want and watch Blender build it

Click-by-click video tutorial, 1:41. GameStudio 0.1.0, Blender 5.2.2 or newer.

## 00:03 Step 1: Open the GameStudio menu

Your game project is open in Blender. To build it with Claude Code, open the GameStudio menu.

## 00:09 Step 2: Choose Open in Claude Code

and choose Open in Claude Code.

## 00:12 Step 3: Install Claude Code if it's missing

If Claude Code isn't installed yet, GameStudio offers to install it, with Anthropic's official installer. One click, and Claude Code opens in your project when it's ready.

## 00:23 Step 4: Claude Code starts: click Done

Claude Code starts in a terminal, in your project folder. The first time, it asks you to log in. GameStudio suggests a few prompts to start from. Click Done.

## 00:33 Step 5: Describe what you want

Now, in the terminal, say what you want in plain words. Here: add five more gems in a ring around the island, and make them spin.

## 00:41 Step 6: Claude looks at the scene

Claude Code connects to Blender and looks at the scene first. The status bar shows what it's doing.

## 00:47 Step 7: Watch the gems appear

Then it builds. The five gems appear in Blender as Claude works.

## 00:52 Step 8: It adds the components

It gives them the Collectible and Spin components, so they spin, and the player can pick them up like the other three.

## 00:58 Step 9: Click Claude in the top bar

Claude says it's done. Everything it did is listed in Blender: click Claude in the top bar.

## 01:03 Step 10: Click an action

Here's what it did, newest first. Pause stops its changes, and Protect keeps the objects you select safe from it. Click an action to see what it made.

## 01:13 Step 11: Undo to Here takes it back

Blender selects the five gems it made. Undo to Here takes Blender back to just before that action, so every change Claude makes can be undone.

## 01:22 Step 12: Press Esc to close it

Redo brings it back, as the tooltip says. Press Escape to close the list.

## 01:28 Done: Press F5 to play

That's how you build with Claude Code: describe what you want, watch Blender update, and undo anything you don't like. Press F5 to play your game.
