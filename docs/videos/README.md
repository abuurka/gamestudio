# GameStudio video tutorials

**[Open the video gallery](index.html)** · **[Read the illustrated manual](../manual.html)**

Click-by-click lessons for GameStudio 0.1.0 and Blender 5.2 or newer. Every step shows the real interface: the cursor moves to the control, clicks it, and the screen changes as it does in Blender. Each video has an ElevenLabs English voiceover (the stock River voice) and captions in the picture.

Open a video in your browser or video player. The gallery works locally when this folder stays together. The separate subtitle files are for reuse in an editor or on a hosting service; turning on a subtitle track as well shows duplicate captions.

The screenshots come from a scratch Blender profile with neutral paths and project names, and every video is checked with text recognition on its shots and frames before it is published. No personal account names, local paths, API keys or private voice recordings are included. Code editors, coding-agent terminals and browsers are recreated windows, because the real ones show account details.

The videos introduce the workflow. The manual covers installation details, project trust, components, game controls, troubleshooting and publishing. Some keyboards need Fn with the function keys.
