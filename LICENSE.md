# Licences

GameStudio has several parts under different licences. A file with an `SPDX-License-Identifier`
line has that licence.

| Part | Licence | Text |
|---|---|---|
| The Blender extension, `blender/gamestudio/` | GPL-3.0-or-later | [blender/gamestudio/LICENSE](blender/gamestudio/LICENSE) |
| The runtime packages, `runtime/packages/*/` | MIT | `LICENSE` in each package |
| The project templates' code and text, `blender/gamestudio/project_templates/`, and the script templates, `blender/gamestudio/script_templates/` | MIT-0 | [project_templates/LICENSE](blender/gamestudio/project_templates/LICENSE), [script_templates/LICENSE](blender/gamestudio/script_templates/LICENSE) |
| The starter template's sounds, music and UI images | CC0-1.0 | [starter/assets/LICENSE.txt](blender/gamestudio/project_templates/starter/assets/LICENSE.txt) |
| The demo game, `examples/demo-game/` | MIT-0 | [examples/demo-game/LICENSE](examples/demo-game/LICENSE) |
| Everything else: tests, tools, `editor/`, `docs/` | GPL-3.0-or-later | [COPYING](COPYING) |

MIT-0 and CC0 ask for no credit, so a game made from a template is yours to license as you like.
[README.md](README.md#developing-gamestudio) says what that means for your games. This is not legal
advice.
